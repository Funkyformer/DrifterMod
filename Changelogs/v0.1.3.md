## Misc Changes
- Fabricated keyword will now properly appear on cards.
- Fabricated cards no longer crash the game at the end of the turn. Oops!
- There is now a Fabricate+, which creates an upgraded card instead.
- Semi-Auto cards will not return to hand if they are permanently set to free.
- Blade cards now generate 3 Charge (was 2) when dealing damage
- Modular cards can now be generated in combat, and instead have been specifically excluded from Fabricate.
